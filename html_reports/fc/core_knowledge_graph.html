How to read the graph

  • Solid arrows are top-level from core.X import … imports — they resolve at module load time and define the hard dependency.
  • Dashed arrows labelled "lazy" are imports inside function bodies. They exist to break cycles (e.g. models ↔ users would cycle if eager) or to keep package import cheap.
  • Three nodes — __init__.py, migrate_users.py, runtime_history.py — have no inbound or outbound edges within core/. They're used by server.py or offline scripts, not by other modules in this package.
  • backtest_runner.py is the rightmost sink: everything below L4 ultimately funnels into it. It is the only file that imports every other layer.
