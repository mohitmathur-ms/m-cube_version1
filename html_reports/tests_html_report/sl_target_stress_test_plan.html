How to read each case

Each test case below is a complete portfolio specification. Parameters are grouped into 12 categories — every category appears in every case, so all settings are covered each time. param=value tokens carry the exact configuration.

Design principle. These cases deliberately stack conflicting and boundary values — multiple SL movers fighting over current_sl, timing gates overlapping, opt-in flags combined, degenerate numerics (0, negative, threshold < floor), and format/engine mismatches. Each is built to break something.
