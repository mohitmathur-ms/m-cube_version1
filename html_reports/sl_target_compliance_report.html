Update — §8.1 directional-close fill now implemented (frontend + backend). The one "Not as specified" item — the §8.1 directional-close exit-fill — has been built this session as a per-portfolio toggle (directional_close_fill) with the _USE_DIRECTIONAL_FILL env override. The directional close is the exit base price (LONG→bid close, SHORT→ask close; the close rung kept when bid/ask is missing). Per spec it composes with the VWAP fill rather than replacing it: VWAP owns the leg SL/Target exits (§4.2), the directional close is the base for squareoff / EOD exits (§8.1) — disjoint exit sets. Update — §3 Mark Price now implemented (frontend + backend). Added as the "mark" exit-price format: per the project's agreed model (approach B) the mark price is proxied by the previous bar's close (rolling _prev_close), so SL/Target triggers consult the last settled price and intra-bar wicks don't fire (the spec's anti-manipulation intent). Crypto-only per spec — on_start downgrades to OHLCV with a log on non-crypto venues. This was the last ❌ Missing item; there are now no Missing or Not-as-specified rows. See §8 and §9.
Update — §3 / §4.2 exit-fill VWAP now the real session VWAP. _build_vwap_lookup now computes the spec's volume-weighted, session-cumulative VWAP (Σ((H+L+C)/3·volume) / Σ(volume)) from each bar's volume, reset at the venue's session_start_time (UTC, from adapter_admin/adapters_config). The bare-typical proxy is gone; it only falls back to the typical price when a session has no volume yet. (Per the spec volume caveat, FX/commodity volume is broker quote-size, so the VWAP weights quote depth there — spec-correct by definition.) Verification of the fill against §4.2 also surfaced and fixed a real bug — the BUY/long exit was using MAX(vwap, hit) where the spec mandates MIN (conservative, receive less); short was already correct. And Format B (single OHLCV/LAST series) is now implemented, so crypto / OHLCV-only slots get a §4.2 fill instead of nothing. This closes the two VWAP-definition partials.

Architectural notes (by design, not gaps)

  • No mid-bar hard halt. Portfolio/user/tag caps are enforced post-hoc by walking the merged equity curve and dropping/replaying trades after the clip — slots themselves run to completion. This is a deliberate Path-A design choice, not a per-feature miss.
  • Exit Sell First & leg Underlying type are intentionally N/A for FX/crypto (independent per-slot engines; leg underlying lives at portfolio level per spec).
  • Env flags are overrides only. vwap_exit_fill, portfolio-aggregate Move-SL and portfolio ReExecute replay are all config-driven now; _USE_VWAP_FILL / _USE_PF_AGG_MOVE_SL / _USE_PF_REEXEC_REPLAY remain only as manual parity-tooling overrides.
  • Path B caveat. The VWAP exit-fill, the new directional-close exit-fill, and the cross-slot Move-SL leg-event surfacing are Path-A only; under _USE_BACKTEST_NODE=1 both fill models are a no-op (the aggregate-PnL trigger still works as it reads equity curves only).
