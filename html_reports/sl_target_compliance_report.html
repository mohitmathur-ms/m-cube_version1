Update — two remediation passes. Pass 1 shipped: §9 timing-ordering save validation, Winter Time Adjustment (+1h DST), and the conservative VWAP exit fill (with §8.1 SqOff enhancement and per-format fills) promoted from a hidden env flag to a per-portfolio toggle. Pass 2 promoted the two remaining engine-side partials from env-flag-gated to config-driven: the portfolio-aggregate Move-SL (§5.5) and the portfolio ReExecute replay (§2.4, incl. the entry-price ReExecute variants) now activate automatically whenever the user configures them — no env flag. Two items remain genuinely blocked and are documented rather than stubbed: Mark Price (no mark-price data) and Portfolio Tags (no multi-portfolio orchestrator). The only remaining partials are the cross-portfolio "…Other Portfolio" actions (need a multi-portfolio session) and the literal directional-close fallback chain (subsumed by the now-active VWAP fill).
Pass 3 — Portfolio Tags. The §11 tag tier is now implemented as a faithful clone of the working user tier one level down: a config/tags.json registry + _TAG_PNL_AGGREGATOR, a portfolio_tag field, tag-scoped clips reusing _user_sl_clip/_user_tgt_clip (scope_label="TAG") merged via _earliest_clip, /api/tags/* endpoints, a Timing-tab selector, and hierarchical limit validation (portfolio ≤ tag ≤ user, both sides) on save. The cross-portfolio session caveat from Pass 2 is the same orchestrator dependency, now the only structural limit (a "run all my portfolios" flow). Mark Price stays the single hard Missing — it needs a data feed that doesn't exist.

Note on gated features

Three former env-only features are now saved per-portfolio controls: vwap_exit_fill (Exit Settings), the portfolio-aggregate Move-SL (Move-SL section), and the portfolio ReExecute replay (driven by the SL/Target action choice). Their legacy env flags — _USE_VWAP_FILL, _USE_PF_AGG_MOVE_SL, _USE_PF_REEXEC_REPLAY — are retained only as manual overrides for parity tooling. Recommend documenting these (now config-backed) flags in the CLAUDE.md "Runtime flags" table for completeness.
